Mix & Match and Bundle programs counted in boxes, cases or any unit of measure: “any 3 boxes, cheapest box free”. Installed automatically when both apps are present; neither is modified.

Why this module

Shops that sell by the box want set promotions by the box too.

With POS Mix & Match alone

  • Sets are counted in product units: “3” means 3 bottles.
  • “Cheapest item free” frees one unit.
  • No link with the packaging scanned at the till.
  • No rule for shops where packaging is switched off.

With this bridge

  • The rule’s Count by applies: “3” can mean 3 boxes or 3 dozens.
  • “Cheapest item free” frees the cheapest box.
  • The package of each line (or a Package Type) is used, as in your loyalty rules.
  • Where Packaging Is Off: count units, or the rule doesn’t apply.

How it works

Nothing to configure on the bridge itself.

1
Install both apps
POS Mix & Match and Bundle Promotions and POS Loyalty Packaging & UoM; this bridge follows.
2
Switch packaging on
Packaging scanning and Pricelists by Package in the POS settings, as for the packaging apps.
3
Count the rule
On a Mix & Match or Bundle rule: Count by Package (or Unit of Measure).
4
Sell boxes
Sets and rewards are counted in boxes at the till.

Features

Screenshots use demo data: Water 330 ml (2.00) and Sparkling Water 330 ml (2.50), both sold in a Box of 6 (package type Box), prices in SAR with 15% VAT included.

Feature 1

Count a set in packages

The rule “any 3, cheapest free” with Count by Package and Package Type Box: a set is 3 boxes of 6. Where Packaging Is Off decides what shops without packaging do. The fractional package rounding is hidden on these rules: sets always count packages exactly.

Feature 2

The cheapest box is free

2 boxes of Water (12 × 2.00) and 1 box of Sparkling Water (6 × 2.50) complete the set. The cheapest box, Water at 12.00, is free.

17 bottles are not enough: 3 boxes means 18 units, counted across both products.
Feature 3

Works for both program types and all rewards

Each bundle part can count in its own way (a case of drinks plus one unit of snacks). % discount, fixed price per set and cheapest item(s) free all follow the counting of the rules.

Built for real-world corner cases

The bridge reuses the counting engine of POS Loyalty Packaging & UoM.

Loose units and boxes in one order
6 loose bottles count as one box of 6; a line can be split between sets.
Product without that package
Not counted for a package rule, never guessed.
Different units of measure
Converted within the same UoM category; other categories are refused.
Shop with packaging off
Count units (standard) or Rule doesn’t apply (a bundle with such a part gives no reward there).
Standard programs
Promotions, loyalty and buy X get Y keep the behaviour of POS Loyalty Packaging & UoM.
Offline
Packagings are loaded with the session: no server call while selling.
